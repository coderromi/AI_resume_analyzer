# 📄 AI Resume Analyzer

An AI-powered resume analysis tool built with Python and Google Gemini. The application reads a resume PDF, extracts its content, and uses Generative AI to provide a structured analysis.

## 🚀 What This Project Does

The application:

- Reads a resume from a PDF file
- Extracts the resume text using PyPDF
- Sends the extracted content to Google Gemini
- Identifies technical skills and programming languages
- Summarizes projects and education
- Highlights strengths
- Suggests potentially useful missing skills
- Provides specific resume improvement suggestions

## 🔄 How It Works

```text
Resume PDF
    ↓
PyPDF
    ↓
Extract Resume Text
    ↓
Google Gemini
    ↓
AI Resume Analysis
    ↓
Skills + Projects + Strengths + Improvements
